Prerequisites

Workspace

  • Copy .env.remote.example → .env.local
  • npm install
  • npm run setup:playwright

Required secrets

  • Azure OpenAI — API key, endpoint, model names
  • SitecoreAI automation — client ID/secret (Environment → Automation)
  • BQ_SITECORE_ENVIRONMENT_ID
  • BQ_SITECORE_ENDPOINT (e.g. bqAuthoring)
Where to find SitecoreAI values: Deploy → Credentials (Environment Automation) and Environment Details. Full catalog: bq/.env.remote.example.

Failure mode — logo fidelity

Always compare section-*-tablet.png vs attempt-1 vs sitecoreize-proof before trusting CM. Prompts now harden “full HTML SVG / HTML wins for logos.”
17

Force / cache · failure signatures

Force / cache

  • No --force: skip unchanged (hash + package)
  • --force / :components|:definition: re-AI
  • --force:yaml: re-emit YAML only
  • --only section-NN: scope AI + emit
  • --codegen-only / --wire-only: split A/B

Failure signatures

  • Empty sections → capture / Playwright
  • …LogoSvg is not defined → bad definition seed at generate
  • Expected "}" … ComponentTemplateDefinition → broken def close
  • authoring:generate exited 1 → Sites API / ser / bad module
  • Wrong logo in attempt-1 → visual AI
  • Wrong only after sitecoreize → svgMarkup / Image preview
